# Pseudonyme Schülercodes ohne PIN

Im Klassenordner stehen keine Namen: Speicherstände heißen nach dem Schülercode, und die Namensliste liegt nur auf dem Laufwerk der Lehrkraft. Eine PIN gibt es bewusst nicht, um den Einstieg einfach zu halten. Der Schutz gegen das Weiterarbeiten unter fremdem Code beruht darauf, dass Codes nicht erratbar sind.

## Consequences

- Wer den Code eines Mitschülers kennt, kann dessen Stand bearbeiten. Das ist in Kauf genommen.
- Rechtlich bleibt es Pseudonymisierung; die DSGVO gilt weiterhin.
