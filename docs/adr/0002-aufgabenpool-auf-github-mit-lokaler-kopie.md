# Aufgabenpool auf GitHub mit lokaler Kopie im Klassenordner

Der Aufgabenpool liegt als JSON-Datei in diesem Repository und wird über GitHub Pages geladen, damit er ohne Neuverteilung der Dashboards erweitert werden kann. Neue Aufgabenpakete kommen per Pull Request und werden von der Lehrkraft geprüft. Das Lehrer-Dashboard legt beim Start eine Kopie im Klassenordner ab, die Schüler nutzen, wenn GitHub nicht erreichbar ist. Schülerdaten verlassen das Schulnetz nie.
