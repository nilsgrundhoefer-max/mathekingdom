# Klassenwechsel, Schuljahreswechsel und Wiederholung

Nils wünschte am 27.11.2026, dass Schüler die Klasse und die Klassenstufe wechseln können (auch als Wiederholer) und dass am Ende des Schuljahrs aus der 5a die 6a wird, mit Code 5A-ABCD → 6A-ABCD und erhaltenem Profil, gesteuert im Administrator-Dashboard. Entschieden in der Fragerunde (Q1 bis Q6, Q24, Q25).

**Klassenwechsel im laufenden Schuljahr.** Nur der Administrator verschiebt einen Schüler, unter „Namen und Codes“ mit „Klasse wechseln“. Name, PIN, Speicherstand, Zielniveau, Notiz und ungeöffnete Münzgaben ziehen mit; Sonderauftrag, Nachricht, Hilferuf und gesperrte Meilensteine verfallen, der Sitzplatz wird frei. Der Code behält seinen hinteren Teil und bekommt das neue Klassenkürzel. Die neue Datei wird zuerst geschrieben und gelesen; erst dann ändern sich die Klassendaten und die alte Datei wird gelöscht. Die Backups bleiben bei der alten Klasse. Verworfen: den Code ganz neu vergeben, weil Kinder ihren Code auswendig kennen.

**Alter Code.** Steht ein Code im aktuellen Schuljahr nicht in seiner Klasse, sucht das Schüler-Dashboard in den Klassendateien des aktuellen Schuljahrs einen Code mit demselben hinteren Teil. Die PIN wird trotzdem geprüft, und das Kind sieht einmal „Dein Code heißt jetzt 6A-K4M2“. Verworfen: eine Umzugsliste im Schulverzeichnis, weil die Klassendateien die Codes schon enthalten und eine zweite Liste veralten kann. Die Suche liest nur, wenn der Code nicht passt.

**Schuljahreswechsel.** Eine Tabelle mit allen Klassen des aktuellen Schuljahrs ersetzt die Übernahme je Klasse. Vorschlag ist dieselbe Klasse eine Stufe höher (5a → 6a); nach Klasse 10 wird niemand übernommen. Je Klasse lässt sich „alle nach“ setzen, je Schüler eine andere Klasse, dieselbe Stufe (Wiederholung) oder „nicht übernehmen“. Fehlende Klassen entstehen mit den Lehrkräften der bisherigen Klasse. Mit ziehen Name, PIN, Speicherstand und Zielniveau; Notizen, Sitzplan, Tore und Aktuelles Kapitel beginnen neu. Wer schon übernommen ist, wird nicht doppelt übernommen. Aktuell wird das neue Schuljahr erst mit einem eigenen Klick, damit die Lehrkräfte bis dahin im alten weiterarbeiten.

**Wiederholung.** Wiederholt wird eine Stufe, wenn ein Schüler im laufenden Schuljahr in eine niedrigere Stufe wechselt oder beim Schuljahreswechsel in derselben Stufe bleibt. Dann kommt alles, was zu dieser Stufe gehört, in ein Archiv im Speicherstand: Siegel, Rückblick, „unter dem Ziel geschafft“, Kronenwahl, Runden, Einstiegscheck, Selbsteinschätzung und die Bearbeitungen dieser Stufe. So zählen für Siegel, Kronen, Rückblick und „Das kannst du schon“ nur noch Bearbeitungen aus dem zweiten Durchgang, ohne dass jede Rechnung ein Datum kennen muss. Stellen im Versuchsprotokoll, die sich andere Stufen merken, rücken nach. Münzen, Wappen und Rang bleiben; der Rang zählt mindestens so viele Siegel wie vor der Wiederholung und sinkt nie. Die Lehrkraft sieht im Schülerfenster „Erster Durchgang“. Verworfen: die alten Siegel stehen lassen (der Wiederholer hätte die Stufe sofort gemeistert und die Aufgabenführung schlüge nichts mehr vor) und alles löschen (das Versuchsprotokoll wird nie zurückgesetzt, ADR 0051).
