# Backup aller Klassendaten aufs Lehrerlaufwerk

Weil alle Schüler auf dem Klassenlaufwerk schreiben und damit auch fremde Speicherstände löschen können, sichert das Lehrer-Dashboard, solange es offen ist, stündlich und beim Schließen alle Speicherstände, die Klassendatei und die Lehrerdaten auf das Lehrerlaufwerk: die letzten 14 Tage täglich, danach wöchentlich für das ganze Schuljahr. Einzelne Speicherstände lassen sich zurückspielen; ist das letzte Backup älter als eine Woche, warnt das Dashboard.
